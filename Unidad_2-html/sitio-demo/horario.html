Como entregar una practica

  1. Traer los cambios con git pull
  2. Crear la rama de la practica con git switch -c "Nombre-de-la-rama"
  3. Trabajar y hacer commits atómicios
  4. Subir la rama con git push
  5. Abrir un pull request en GitHub
  6. Revisar u fusionar el pull request
  7. Volvr a la rama principal (main)
  8. Eliminar la rama de la practica con git branch -d "Nombre-de-la-rama"

Glosario Git: Con lista descriptivas

Commit
Instantanea premanete del proyecto en momento dado
Rama
Linea de trabajo paralela que no afecta al main
Pull
Solicitud de revision para incorporar una rama
